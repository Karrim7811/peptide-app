# V4 Dark Landing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `src/app/page.tsx` as the V4 dark, single-scroll "Intelligence Layer for Peptide Research" marketing surface — fixed particle-network canvas behind sequential scenes plus interactive checker/stacks/bloodwork/chat sections, trust band, two-SKU pricing, and CTA.

**Architecture:** Thin `'use client'` `page.tsx` shell composes focused section components under `src/app/_landing/`. A single fixed `<canvas>` (`ParticleNetwork`) morphs across 6 formation modes driven by an IntersectionObserver over `[data-mode]` sections (`useSceneMode`). Reveal-on-scroll via `useReveal`. Real data where free/anonymous-safe (checker autocomplete, curated stacks, pricing); labeled sample demos where the real API is gated (chat/bloodwork/terminal/checker-verdicts).

**Tech Stack:** Next.js 14 App Router, TypeScript, React 18, Tailwind 3.4, Google Fonts (Jost / Cormorant Garamond / JetBrains Mono), HTML canvas 2D. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-07-14-v4-landing-design.md`
**Design source (in repo):** `design_handoff_peptide_cortex_v4/Peptide Cortex v4.dc.html` (the `.dc.html`), `design_handoff_peptide_cortex_v4/README.md`.

## Global Constraints

- Surface: **web only** (`src/`). Do not touch `ios-native/`.
- No new npm dependencies, no new API routes, no Supabase schema change, no Stripe change.
- Palette (dark, add alongside existing light `cx.*`, never overwrite): `ink #050505`, `panel #09111F`, `panel2 #070A10`, `panel3 #0A1421`, `cy #00E5FF`, `pu #7C3AED`, `go #F7B731`, `cymid #3BA7F0`, `pumid #B06BE0`, `dim #B8C5D6`, `muted #8A97AC`, `faint #6B7688`, `faintest #4A5568`.
- **No border-radius** anywhere except explicit circles (dots, play button, chat avatars). Hard-edged rectangles. Hairline grids = 1px gap over an `rgba(255,255,255,0.07–0.1)` bg with opaque cells.
- Fonts: Jost (200/300/400/500) display/body, Cormorant Garamond (300/400 + italics) editorial headlines, JetBrains Mono (300–600) all labels/eyebrows/nav/buttons/terminal/chips/disclaimers (uppercase, letter-spacing 0.14em–0.42em).
- **Disclaimers copied verbatim** from the `.dc.html` — never paraphrase. No "your dose" / individual-dosing phrasing anywhere. Sample surfaces stay labeled "ILLUSTRATIVE"/"sample".
- **AI-consent:** any surface firing a real Claude request must call `useAiConsent().requireConsent()` and receive `true` first. The landing fires no live AI call; "Open in app →" CTAs route to the real gated tools.
- Respect `prefers-reduced-motion`: canvas → single static draw (no rAF); paper-feed/pipeline/typewriter/reveals resolve to their end state immediately.
- Verification per task: `npm run build` must pass, then drive the affected section in a browser (dev server), then commit. There is no unit-test runner in this repo — do not add one.

- [ ] **Step 1: Create `tokens.ts`**

```ts
export const CX = {
  ink:'#050505', panel:'#09111F', panel2:'#070A10', panel3:'#0A1421',
  cy:'#00E5FF', pu:'#7C3AED', go:'#F7B731', cymid:'#3BA7F0', pumid:'#B06BE0',
  dim:'#B8C5D6', muted:'#8A97AC', faint:'#6B7688', faintest:'#4A5568',
} as const
export function modeColor(m: number): string {
  return m === 2 ? CX.pu : m === 4 ? CX.go : CX.cy
}
export function prefersReducedMotion(): boolean {
  return typeof window !== 'undefined'
    && window.matchMedia?.('(prefers-reduced-motion: reduce)').matches === true
}
```
